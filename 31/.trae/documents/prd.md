## 1. 产品概述

多源音视频字幕自动对齐校准服务——一个专业的字幕时间轴校准工具，解决字幕与视频语音不同步的普遍问题。用户上传视频文件和独立字幕文件（SRT/ASS），系统自动检测视频中的语音时间戳，将字幕逐句对齐到实际时间轴，修正偏移量超过200ms的句子，并支持手动拖拽微调。

- 目标用户：字幕翻译组、视频创作者、影视后期人员、教育内容制作者
- 核心价值：将原本需要人工逐句听写校准的数小时工作压缩至分钟级自动完成，同时保留精确的手动微调能力

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱注册 | 上传文件、自动对齐、手动校准、导出结果、查看历史 |
| 管理员 | 系统分配 | 全部权限 + 用户管理 + 系统监控 |

### 2.2 功能模块

1. **工作台页面**：文件上传区、视频预览播放器、时间轴编辑器、字幕列表面板、对齐状态总览
2. **校准历史页面**：历史记录列表、搜索筛选、历史对比、重新加载

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 文件上传区 | 支持拖拽上传视频（MP4/MKV/AVI）和字幕（SRT/ASS）文件，显示上传进度和文件信息 |
| 工作台 | 视频预览播放器 | 内嵌播放器，播放/暂停/跳转，点击字幕自动跳转到对应时间点，波形可视化 |
| 工作台 | 时间轴编辑器 | 可视化时间轴，字幕块可拖拽调整起止时间，语音活动区域高亮显示，偏移超过200ms的句子标红提示 |
| 工作台 | 字幕列表面板 | 字幕文本编辑，逐条显示原始时间 vs 校准时间，偏移量数值，快捷调整按钮 |
| 工作台 | 对齐状态总览 | 显示对齐进度、已修正句数、平均偏移量、整体评分 |
| 工作台 | 导出面板 | 支持导出SRT/ASS格式，选择应用全部校准或仅手动调整项 |
| 校准历史 | 历史列表 | 按时间倒序显示校准记录，包含视频名、字幕文件、校准时间、修正句数 |
| 校准历史 | 详情查看 | 重新加载历史校准结果到工作台，查看原始/校准后对比 |

## 3. 核心流程

用户上传视频和字幕后，系统提取音频并执行语音活动检测（VAD），生成语音时间戳列表。随后将字幕时间戳与语音时间戳进行智能匹配，计算偏移量。偏移超过200ms的字幕自动修正，用户可在时间轴上拖拽微调。校准完成后可导出对齐后的字幕文件，校准记录存入数据库。

```mermaid

    "E" --> "F{偏移量 > 200ms?}"
    "F" --> "是" --> "G[自动修正偏移]"
    "F" --> "否" --> "H[保留原始时间]"
    "G" --> "I[返回校准结果到前端]"
    "H" --> "I"
    "I" --> "J[时间轴可视化展示]"
    "J" --> "K{用户手动微调?}"
    "K" --> "是" --> "L[拖拽调整字幕块位置]"
    "K" --> "否" --> "M[确认导出]"
    "L" --> "M"
    "M" --> "N[导出SRT/ASS文件]"
    "M" --> "O[保存校准历史到数据库]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰色系（#1a1f2e 背景）+ 亮青色强调（#00d4aa）
- 辅助色：琥珀色警告（#f59e0b 用于偏移超限提示）、红色错误（#ef4444）
- 按钮风格：圆角微凸（rounded-lg），带细微阴影和hover渐变
- 字体：标题使用 "JetBrains Mono"（等宽技术感），正文使用 "Noto Sans SC"
- 布局：深色主题工作站风格，三栏布局（左侧文件/字幕列表 + 中央视频/时间轴 + 右侧状态面板）
- 图标风格：线性描边图标（lucide-vue-next）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 文件上传区 | 虚线边框拖拽区域，渐变背景，上传图标动画，文件信息卡片 |
| 工作台 | 视频预览播放器 | 深色背景播放器，底部控制栏，波形叠加层，进度条同步高亮 |
| 工作台 | 时间轴编辑器 | 横向时间刻度尺，可拖拽字幕块（颜色区分已修正/未修正/手动调整），语音活动热力条，缩放/滚动控制 |
| 工作台 | 字幕列表面板 | 可滚动列表，每行显示序号+文本+时间+偏移量，行内编辑，悬停高亮 |
| 工作台 | 对齐状态总览 | 环形进度条，统计数字卡片，评分徽章 |
| 工作台 | 导出面板 | 格式选择下拉，导出按钮带动画，选项复选框 |
| 校准历史 | 历史列表 | 表格布局，排序/筛选控件，行点击跳转详情 |
| 校准历史 | 详情查看 | 对比视图（左原始右校准），差异高亮 |

### 4.3 响应式策略

- 桌面优先设计，最低支持1280px宽度
- 三栏布局在1024px以下折叠为上下布局
- 时间轴组件支持触控拖拽（touch事件）
- 视频播放器自适应容器宽度
